# מינוח: סוג ארגון, ערכה וכלים

**הוחלט 12.10.2026 (Tommy).** ההגדרות המחייבות ב-`glossary.he.md`.

| בממשק ובשיחה | משמעות | בקוד |
|---|---|---|
| סוג ארגון | "איזה סוג ארגון אתם?" | `packId` |
| ערכה | סוג הארגון עם כליו ("ערכת ועד בית") | `pack` |
| כלי | יחידת יכולת שמדליקים ומכבים | `module` |
| כלים מיוחדים | הכלים של ערכה מסוימת | `pack.modules` |

## איך זה נראה בממשק
- תפריט הניהול: "מודולי ועד בית" → **"הכלים של ועד הבית"**.
- הגדרות: "סוג ארגון ומודולים" → **"סוג ארגון וכלים"**.
- הקמת ארגון, שלב 2: **"איזה סוג ארגון אתם?"** ואז בחירת כלים.
- כלי מערכה אחרת: תג "מגיע מבית כנסת".
- הבסיס המשותף לא נקרא "כלים", רק בשמו.

## נפסל
"מודול" בממשק (מילה טכנית), "חבילה" בממשק (נשמע כמו תמחור), "יכולות" (מופשט), "תוספות" (רומז על תשלום), "תבנית" (נשמע חד-פעמי).
