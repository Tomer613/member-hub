# Design boards

These `.dc.html` files are the **sources** of the design boards, not pages you can open in a browser. Opened directly they show raw template text (`{{letter}}`), because they need the design viewer's runtime.

To look at them, use the Design artifact (private link in `docs/design-direction-d.he.md`). They are kept here so the work is not lost and so an agent can read the exact markup and values when building screens.

Source of truth for values is `src/styles/tokens.css`, not the boards.
